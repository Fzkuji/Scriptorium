写入原则

段落标识不消失。内容可以更新、段落可以移动合并，但此前存在的每个标识都必须仍能在某一段落上找到——派生视图与其他段落靠它引用这条记忆。

只许局部编辑禁止整文件重写，标识天然留在原地
标识只增不减可以往段落上加，不能拿掉
新进展另起段落原事实仍成立时不覆盖它
标识归代码模型只写正文与时间来源

段落标识的稳定性

标识由代码生成，模型不接触。它标记的是段落这个容器，不是容器里的内容。

情形段落标识说明
正文被更新不变追加脚注记录新版本的时间来源
段落被重组移位不变换了位置还是同一段
一段拆成两段原标识留其一另一段是新段落，新建标识
多段合并成一段一个主标识，其余成为别名旧标识仍可达，但派生视图只渲染一次

记忆规模不必单调增长

合并规则让重组可以把同一主题下的多个段落收成一条：段落数下降，标识数不变，旧标识通过 Relations 的 alias 映射继续指向主段落。Timeline 与 Recent 只保留一条正文，增长的是标识密度，不是文本量。
