自组织升级 · 消融链

把改动拆成四点逐一量化。3 样本 s0/1/2 · n=385 · 方案 B。双口径:标准 = judge 原判;严格 = 弃答一律算错(弃答正则 not mentioned|no information|cannot be determined|not specified|unknown)。旧 prompt 的 Not mentioned 被 judge 送分,标准分虚高,故以严格分为准。

05

第 4 点文章化验尸

对 21 道翻错题(s0+s1)逐题归因,拆三桶。

C · 检索选错文件 · 14
B · 写糊 · 7
A · 0

A 写丢 = 0(信息零丢失)· B 写糊 = 7(重写二次换算日期算错、原词被同义替换)· C 在库但检索选错文件 = 14(文章化拆碎话题,事实散落兄弟文件,命中面变小)。

结论 — 文章化不丢信息,败在重写失真 + 检索命中面缩小;成本还是原子行的 3 倍(全程 8h vs 2.5h)。文章化路线砍掉,回归原子行。
